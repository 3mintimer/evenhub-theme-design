# メニュー内のアイコン画像を作る

スマートフォン側のメニュー、設定行、ツールバー用。アプリ一覧に表示する配布用ロゴや、G2 グラスに送る画像とは用途を分ける。

## 形の決め方

まず対象プロジェクトの既存アイコンセット、線幅、表示サイズ、ライセンスを確認する。同じセットに目的の絵柄があれば再利用し、新規の1個だけ別の太さや作風にしない。

Even v2.4.0 の観測では、通常の設定行はモノクロの簡潔な輪郭、下部ナビゲーションは選択時に塗りが増える表現。グラス風の緑や虹色、立体的な影は標準メニュー表現ではない。独自のピクセル調のエッジは、スクリーンショットの倍率・圧縮による段差とも区別する。アプリ画像を切り抜いて新しいアイコンとして使わない。

新規の幾何学アイコンには、次を出発点とする。数値は公式仕様ではない。

- `viewBox="0 0 24 24"`、見える輪郭は概ね2〜22の範囲。線幅1.5〜1.75、線端・角の処理をセットで統一する。
- 正面の単純なシルエット。小さな文字、細かい装飾、複数の主題を詰め込まない。16 / 20 / 24 px の実表示で同じ意味を読めるか確認する。
- 同じ寸法だけでなく、見た目の大きさ・重心・余白を揃える。1xの線がぼけるときは実表示で座標と線幅を調整する。曲線の多いアイコンに一律 `crispEdges` をかけない。
- 装飾用SVGは `aria-hidden="true"` にして隣接ラベルに意味を持たせる。アイコンだけの操作には操作内容のアクセシブル名と十分なタップ領域を付ける。
- 選択・無効・押下・フォーカスを対象部品の状態として作る。選択を色だけに依存させず、塗り、チェック、下線やラベル等を併用する。無効な絵柄を通常状態の薄い情報文字へ転用しない。

同梱の `assets/icons/note.svg`, `activity.svg`, `bell.svg`, `sliders.svg` は、このスキル用に新規作成した見本。公式の Even アセットではない。目的に合わせてパスを編集できる。

## SVG・PNG の使い分け

WebView のモノクロアイコンは SVG を基本にする。インライン SVG は `stroke="currentColor"` / `fill="currentColor"` で親の文字色へ追従させる。外部ファイルを `<img>` で読むだけでは親の `currentColor` は伝わらない。

同梱サンプルは外部SVGを **CSS mask** にし、`background: currentColor` で描く。`.even-menu-icon` と `--even-icon-url` を使えば、light / dark / disabled / 黄色の面で同じ形が適切な文字色になる。色が複数ある画像やロゴはマスクにしない。

```html
<span class="even-menu-icon" aria-hidden="true"
      style="--even-icon-url: url('/icons/note.svg')"></span>
```

PNG 等の画像ファイルが必要な場合は、完成した SVG から透過 PNG を出力する。同じ論理サイズに対して1x / 2x / 3xを作り、テーマ別の前景色を明示する。24 px用なら24 / 48 / 72 px。画像サイズとCSSの表示サイズを混同しない。背景は塗りつぶさず透明にする。既存PNG全体の反転フィルターで両テーマ対応を済ませない。

`scripts/export-icon-png.cjs` は Node.js と `sharp` を使う任意の補助。CSS・SVG・プレビューの利用には不要。PNG出力を使う場合だけ、このスキルのルートで次を実行して `sharp` を導入する。製品アプリへ依存を追加する必要はない。

```sh
npm install --no-save --package-lock=false sharp
```

Node.js のバージョンは利用する `sharp` の動作要件に合わせる。別のSVGレンダラーを使ってもよい。

```sh
node scripts/export-icon-png.cjs assets/icons/bell.svg \
  --output-dir ./output/icons \
  --name bell-light --size 24 --scales 1,2,3 --color '#232323'

node scripts/export-icon-png.cjs assets/icons/bell.svg \
  --output-dir ./output/icons \
  --name bell-dark --size 24 --scales 1,2,3 --color '#EEEEEE'
```

スクリプトは指定色で `currentColor` を解決し、背景を透明のまま保持する。既存出力へは上書きしない。SVGの装飾や多色を自動で再設計するものではない。新しい絵柄が必要なら先にSVGを作り、確認してから書き出す。

写真・複雑なイラストのラスタ画像を明示的に求められた場合は、利用可能な画像生成ツールを使う。標準の小さなメニューアイコンは、既存のアイコン体系かコードで作るベクターが適している。生成画像を使う場合も最終サイズ、輪郭、透過、両テーマの見え方を検証する。

## 完了の基準

同じ実表示サイズで、lightの通常面、darkの通常面、黄色の選択面、無効状態を並べて見る。PNGは透明な四隅・意図した前景色・寸法を確認し、SVG原本とセットで渡す。モバイルの拡大画面だけで線の鮮明さを判定しない。G2グラス用が必要なら、グラス用のサイズ・グレースケール・転送形式に合わせて別工程で作る。
