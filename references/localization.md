# System language と多言語のトーン

Even v2.4.0（2026-10-28）の System language で9言語の選択肢・見出し・注記をBrightで確認した。日本語・韓国語では単位設定の本文も確認した。観測したUIの語と、このスキル用の作例の翻訳を区別する。原本スクリーンショットや個々の端末の設定値は配布しない。

## 観測した選択肢

一覧は通常面に並び、右端のチェックで選択を示す。言語名は選択中の言語へ訳し直さず、その言語の自称で表示されていた。

| 一覧の表示 | Webの `lang` の例 | 切替後の見出し |
|---|---|---|
| English | `en` | System language |
| 简体中文 | `zh-Hans` | 系统语言 |
| 繁體中文 | `zh-Hant` | 系統語言 |
| 日本語 | `ja` | 表示言語 |
| Español | `es` | Idioma del sistema |
| Français | `fr` | Langue du système |
| Deutsch | `de` | Systemsprache |
| Italiano | `it` | Lingua di sistema |
| 한국어 | `ko` | 시스템 언어 |

Webのタグは実装上の例であり、Evenの内部IDやSDKの列挙値を確認したものではない。すべてのプラグインに9言語対応を要求せず、対象プロジェクトの対応範囲を維持する。

## 実画面から得た判断

- Unit preferenceの見出しは日本語で「単位の設定」、韓国語で「단위 설정」。短く機能を示す語を選ぶ。
- 本体UIの見出し・補助文は言語変更で更新された。グラスは再起動後に適用する旨の注記があった。画面UIの更新とグラスへの反映を分ける。物理グラスでの反映は未確認。
- 表示言語・日付形式・測定単位は独立した設定として扱う。表示言語の変更から書式や単位を勝手に上書きしない。
- 配色・角丸カード・チェック・スイッチの意味は言語に依存させない。ドイツ語・イタリア語・フランス語の注記は複数行になり、中国語は簡体字・繁体字で語と字形が異なる。韓国語は語間の空白を保つ。
- 英語の見出しや製品名が残る箇所はあったが、未翻訳箇所をプラグイン全体へ英語を強制する規則とは扱わない。固有名詞と翻訳対象の操作ラベルを区別する。
- フォント名や内部フォールバックは画像だけから断定しない。

## WebView へ取り込む

1. 既存の翻訳辞書と選択・保存経路を使う。言語ごとにページを作り直したり、英語のDOM文字列を後から一括置換したりしない。ラベル、補助文、入力の説明、エラー、状態通知、アクセシブル名まで同じ辞書で扱う。
2. 実際に表示する言語へ `html[lang]` を揃える。一部だけを別言語で表示する見本や言語名の一覧は、そのサブツリーに適切な `lang` を付ける。簡体字・繁体字を同一の字体だと仮定しない。
3. 対象OSで利用可能なシステムフォントと適切なCJKフォールバックを使う。CSS作例では `:lang(zh-Hans)` / `:lang(zh-Hant)` / `:lang(ko)` により、簡体字・繁体字・ハングルの候補を分けている。PingFang SC / TC、Apple SD Gothic Neo等は利用可能な場合の候補で、Evenのフォントを特定・同梱したものではない。日本語用フォントをすべての言語へ強制したり、ラテン文字向けの強い負の字間をCJKへ一律適用したりしない。韓国語は `word-break: keep-all` と長い語の折返しを組み合わせ、語間を優先して改行する。
4. 単語や文章を自然に折り返し、固定高で切らない。長い欧文には単語単位の折返しを基本にし、`lang` と `hyphens: auto` で利用可能な言語別のハイフネーションを使う。辞書のない環境や長い連結語・URLでも、必要に応じて折り返せるようにする。ラベル・右値・アイコンが競合しないよう `min-width: 0` と伸びる行高を保つ。
5. 言語変更は文字列を更新する。スイッチ、入力値、選択中ソース、明示テーマ、日付形式や単位の設定を消さない。ロケール依存の書式化が必要なときも、既存の明示設定を尊重する。
6. Even本体のSystem languageが `navigator.language` やプラグインへ自動反映されるかは未確認。ホスト由来の信号は現在のSDK・型定義・実機で存在と挙動を確かめる。未確認の `getSystemLanguage()` や言語イベントを創作しない。代替として使うOS／ブラウザ言語と、アプリの明示選択を区別する。

## 見本と確認

`assets/theme-preview.html` は9言語へ見本画面だけを切り替える。検証用コントロールは日本語のまま。`assets/preview-locales.js` はこのスキルの作例で、公式の完全な翻訳辞書ではない。言語変更は入力・選択・テーマを保持する。

light / darkと320〜430 CSS pxの幅で、対応するCJKと長くなる欧文を比較する。文字欠け・省略・重なり・固定高・ボタンの高さを確認する。翻訳キーが画面に露出したり、言語変更だけで実通信が始まったりしないことも確かめる。

初期の言語対応版では9言語 × 2テーマ × 320 / 390 / 430 CSS pxの54通りをブラウザで確認した。これは下部メニュー見本を追加する前の検証であり、現行版の全画面保証ではない。現在の静的チェックは `node scripts/check.cjs` で再実行できる。Even内WebViewの言語同期、物理グラス、各機能の全画面・全状態は未確認。

本体を操作して比較する場合は開始時の選択をその場で確認し、変更を保持する指定がなければ戻す。復元はチェックと表示内容で確認する。
