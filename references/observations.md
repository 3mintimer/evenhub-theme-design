# 観測の範囲と実装上の補完

基準は2026-10-28に確認したEven v2.4.0の実画面。アプリ内部のデザイントークン、HTML/CSS、フォントファイルを抽出した結果ではない。公開版には原本スクリーンショット、アカウント情報、健康データ、会話ログ、端末固有の設定状態を含めない。

## 観測と推奨を分ける

- ページ地はlight約`#EEEEEE` / dark約`#232323`、面は`#FFFFFF` / `#2E2E2E`を参考にする。広い無地部分の色を基準にした近似であり、公式値ではない。
- 黄色い面は両テーマとも約`#FDF99E`、その上は濃い文字。今回の観測範囲だけから全画面・全状態の有彩色を制限しない。
- 文字・無効色・細部の寸法は誤差を含む。CSSの文字サイズ、余白、角丸は実装用の出発点。
- スイッチは2値のまま同じつまみがスライドする。オフ時の細部と160msのアニメーション時間は実測値ではない。
- システムフォントの候補、エラー色、フォーカス、ホバー、一般的なダイアログは実装上の推奨。フォント名を特定したものではない。

詳細な色・寸法・部品の扱いは [design-reference.md](design-reference.md)、言語の語と実装は [localization.md](localization.md) を参照する。

## 検証範囲

初期の言語対応プレビューは9言語 × 2テーマ × 320 / 390 / 430 CSS pxの54通りで確認した。横方向のはみ出し、文字の切れ、翻訳キー、入力・ソース選択・トグル状態の保持、黄色い面と濃い文字を比較した。明示テーマとOS設定が異なる場合、自動モードでOS設定が変化した場合も確認した。

その後追加した下部メニューとsafe areaのパターンは、意図しない線を防ぐための推奨実装。現行版のブラウザ目視による再検証は未実施で、以前の54通りの結果をその検証済み根拠とは扱わない。下側余白0 / 20 / 34pxの選択は模擬値であり、実機のinset実測ではない。

`node scripts/check.cjs` は静的な参照、JavaScript構文、翻訳、SVG、配布ファイルの基本的なチェックを再実行する。ブラウザの描画確認を代替しない。

Even内WebViewでのテーマ／言語の伝播、ソフトキーボード、端末ごとのinset処理、物理G2の表示・言語適用は未確認。ブラウザ・Simulator・実行中WebView・物理グラスの結果を区別する。
